# Qiskit v2.x Certification Practice Exam

Welcome to the Qiskit v2.x Practice Exam repository. This project is designed to help candidates prepare for the *IBM Certified Associate Developer - Quantum Computing v2* exam.

## Project Structure
- `practice_exam.md`: Contains the full practice test with over 20 questions.
- `solutions.md`: Contains the answer key with detailed technical explanations.
- `qiskit_v2_database.json`: The raw JSON database of questions for easy parsing and integration into web apps or flashcards.
- `exam_simulator.ipynb`: A Jupyter Notebook sandbox to empirically test your circuits and primitive configurations.

## Scope of the Exam
The questions in this repository are strictly aligned with Qiskit version 2.x. They focus heavily on:
* **Instruction Set Architecture (ISA):** Using `generate_preset_pass_manager`.
* **V2 Primitives:** `SamplerV2`, `EstimatorV2`, and the Primitive Unified Bloc (PUB) structures.
* **Quantum Information:** Manipulation of vectors, matrices, and observables using `qiskit.quantum_info`.
